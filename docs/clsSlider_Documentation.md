## Описание

Класс `clsSlider` представляет собой реализацию пользовательского элемента управления "слайдер" для VBA. Он позволяет создавать интерактивный ползунок для выбора значений в заданном диапазоне. Слайдер может быть как горизонтальным, так и вертикальным, и состоит из трех элементов управления Label: пустой линии, заполненной линии и кнопки ползунка.

## Структура класса

### Перечисления

#### PositionValue
Определяет возможные позиции для отображения значения слайдера.

- `Top` (1) - значение отображается сверху
- `Left` - значение отображается слева
- `Right` - значение отображается справа
- `Bottom` - значение отображается снизу

### События

#### Click
Событие срабатывает при клике на кнопку слайдера.

**Параметры:**
- `control` - объект, на котором произошло событие
- `Value` - текущее значение слайдера

#### Change
Событие срабатывает при изменении значения слайдера.

**Параметры:**
- `control` - объект, на котором произошло событие
- `Value` - новое значение слайдера

### Свойства

#### Version (Get)
Возвращает информацию о версии класса, авторе, датах создания и обновления, лицензии и описании.

#### Locked (Get/Let)
Позволяет заблокировать или разблокировать слайдер. Заблокированный слайдер не реагирует на действия пользователя.

**Тип**: Boolean

#### Enabled (Get/Let)
Управляет доступностью слайдера. Недоступный слайдер отображается серым цветом и не реагирует на действия пользователя.

**Тип**: Boolean

#### Visible (Get/Let)
Управляет видимостью всех элементов слайдера (линия, кнопка, значение).

**Тип**: Boolean

#### VisibleLabelValue (Get/Let)
Управляет видимостью метки, отображающей значение слайдера.

**Тип**: Boolean

#### Icon (Get/Let)
Позволяет задать или получить иконку на кнопке слайдера.

**Тип**: Long

#### PositionLabelValue (Get/Let)
Позволяет задать или получить позицию метки значения слайдера.

**Тип**: PositionValue

#### FormatValue (Get/Let)
Позволяет задать или получить формат отображения значения слайдера.

**Тип**: String

#### ForeColorValue (Get/Let)
Позволяет задать или получить цвет текста метки значения.

**Тип**: XlRgbColor

#### ForeColorBtn (Get/Let)
Позволяет задать или получить цвет текста кнопки слайдера.

**Тип**: XlRgbColor

#### BackColorFull (Get/Let)
Позволяет задать или получить цвет заполненной части линии слайдера.

**Тип**: XlRgbColor

#### BackColorEmpty (Get/Let)
Позволяет задать или получить цвет пустой части линии слайдера.

**Тип**: XlRgbColor

#### Name (Get)
Возвращает имя основной метки слайдера.

**Тип**: String

#### IsHorizontal (Get)
Возвращает, является ли слайдер горизонтальным.

**Тип**: Boolean

#### MinValue (Get/Let)
Позволяет задать или получить минимальное значение слайдера.

**Тип**: Single

#### MaxValue (Get/Let)
Позволяет задать или получить максимальное значение слайдера.

**Тип**: Single

#### Value (Get/Let)
Позволяет задать или получить текущее значение слайдера.

**Тип**: Single

### Методы

#### Initialize
Инициализирует слайдер с заданными параметрами.

**Параметры:**
- `labelSlider` (ByRef MSForms.Label) - основная метка, которая будет использоваться как пустая линия слайдера
- `Value` (Single) - начальное значение слайдера
- `MinValue` (Single) - минимальное значение слайдера
- `MaxValue` (Single) - максимальное значение слайдера
- `VisibleLabelValue` (Boolean) - видимость метки значения
- `FormatValue` (Optional String) - формат отображения значения (по умолчанию vbNullString)
- `PositionValue` (Optional PositionValue) - позиция метки значения (по умолчанию Top)
- `BackColorEmpty` (Optional XlRgbColor) - цвет пустой части линии (по умолчанию rgbLightGray)
- `BackColorFull` (Optional XlRgbColor) - цвет заполненной части линии (по умолчанию rgbGreenYellow)
- `ForeColorBtn` (Optional XlRgbColor) - цвет кнопки (по умолчанию rgbBlack)
- `ForeColorValue` (Optional XlRgbColor) - цвет значения (по умолчанию rgbBlack)
- `Icon` (Optional Long) - иконка на кнопке (по умолчанию 59963)

## Использование

1. Создайте экземпляр класса `clsSlider`
2. Вызовите метод `Initialize`, передав ему метку, которая будет использоваться как основа слайдера
3. Настройте свойства слайдера по необходимости (диапазон значений, формат отображения и т.д.)
4. Обрабатывайте события `Click` и `Change` для реагирования на действия пользователя

## Пример использования

```vba
Dim slider As New clsSlider
Call slider.Initialize(Me.Label1, 50, 100, True, "0.0", clsSlider.PositionValue.Top)
```

## Закрытые методы

#### getValue()
Вычисляет текущее значение слайдера на основе положения ползунка и диапазона значений.

#### SetValue()
Устанавливает значение слайдера и обновляет положение элементов управления.

#### changePositionLabelValue()
Изменяет позицию метки значения слайдера в зависимости от заданной позиции.

#### mLabelBtn_Click()
Обработчик события клика на кнопке слайдера.

#### mLabelBtn_MouseUp()
Обработчик события отпускания кнопки мыши на слайдере.

#### mLabelBtn_MouseMove()
Обработчик события перемещения мыши на слайдере.
