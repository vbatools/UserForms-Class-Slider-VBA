# VBA Slider Class

Этот репозиторий содержит реализацию слайдер-контрола на VBA, который можно использовать в Excel UserForms. Класс слайдера предоставляет более гибкую и функциональную альтернативу стандартному элементу управления scrollbar.

## Возможности

- Настраиваемый внешний вид слайдера (размер, цвета, ориентация)
- Поддержка горизонтальной и вертикальной ориентации
- Настраиваемые минимальные и максимальные значения
- Контроль размера шага для точного выбора значения
- Обработка событий при изменении значения
- Плавные визуальные обновления

## Компоненты

- `clsSlider.cls`: Основная реализация класса слайдера
- `frmTestClass.frm`: Тестовая форма, демонстрирующая использование слайдера
- `modShowForms.bas`: Модуль, содержащий функции отображения форм
- Документация в папке `docs/`

## Установка

1. Откройте книгу `slider_v2.xlsm` в Excel
2. Импортируйте файлы VBA в ваш проект:
   - `vba-files/Class/clsSlider.cls`
   - `vba-files/Form/frmTestClass.frm`
   - `vba-files/Module/modShowForms.bas`
3. Начните использовать класс слайдера в ваших формах

## Использование

Чтобы использовать слайдер в вашей UserForm:

1. Создайте экземпляр класса clsSlider
2. Инициализируйте его с вашей UserForm и желаемыми параметрами
3. Установите свойства, такие как минимальные/максимальные значения, размер шага и внешний вид
4. Обрабатывайте событие ValueChanged для реагирования на взаимодействие пользователя

Смотрите форму `frmTestClass` для полного примера реализации.
